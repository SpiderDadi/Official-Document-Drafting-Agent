# 政策解读分析框架与传播方法论

## 一、核心分析框架

### 1. 三层穿透法（从宏观到微观）

```
第一层：政策原文说了什么
  ├── 核心提法（新概念、新表述）
  ├── 量化指标（目标数字、时间节点）
  └── 政策工具（财政/货币/行政/法律）

第二层：政策意图是什么
  ├── 解决什么问题（痛点识别）
  ├── 调整什么关系（利益格局变化）
  └── 释放什么信号（方向性指引）

第三层：跟我们有什么关系
  ├── 对普通人（收入/就业/消费/生活）
  ├── 对企业（成本/市场/竞争/合规）
  └── 对行业（格局/趋势/机遇/风险）
```

### 2. 五维评估法（政策影响力评估）

| 维度 | 评估内容 | 高分（★★★★★）标准 |
|------|----------|---------------------|
| **覆盖面** | 影响多少人口/企业 | 覆盖全国或主要行业 |
| **紧迫度** | 问题是否亟待解决 | 涉及安全底线或民生痛点 |
| **变化度** | 政策调整力度 | 重大制度创新或方向性转变 |
| **争议度** | 社会关注和讨论热度 | 引发广泛讨论，各方观点鲜明 |
| **可视化** | 能否用数据/图表呈现 | 有丰富的对比数据和案例 |

### 3. 叙事框架：SCQA 模型

适用于口播词和深度分析的结构化叙事：

- **S（Situation）情境**：描述当下背景，建立共识
- **C（Complication）冲突**：指出问题/矛盾/挑战
- **Q（Question）问题**：抛出核心疑问
- **A（Answer）答案**：给出政策解读和观点

## 二、口播词写作方法论

### 1. 黄金前3秒法则

口播开头必须包含以下至少一个元素：
- **反常识**："你可能不知道……"
- **算账**："这笔账算下来，每个人……"
- **场景**："打开你的手机/冰箱/工资条……"
- **悬念**："最近有个信号，很多人没注意到……"

### 2. 节奏控制

| 时间段 | 节奏 | 信息密度 | 情绪曲线 |
|--------|------|----------|----------|
| 0-15秒 | 快 | 低（1个核心信息） | 高（抓住注意力） |
| 15-50秒 | 中 | 中（2-3个信息点） | 中（建立信任） |
| 50-105秒 | 中快 | 高（逻辑论证） | 中高（思维冲击） |
| 105-140秒 | 中 | 中（案例落地） | 中（产生共鸣） |
| 140-160秒 | 慢 | 低（1个金句） | 高（留下印象） |

### 3. 语言转化表（公文 → 口语）

| 公文表述 | 口语化转化 |
|----------|------------|
| 推进农业现代化 | 让传感器进大棚，算力下田 |
| 赋能新质生产力 | 换赛道、换打法、换引擎 |
| 健全多层次保障体系 | 织密安全网，兜住底线 |
| 宏观调控精准发力 | 靶向施策，精准滴灌 |
| 产业转型升级 | 老树发新芽，旧瓶装新酒 |
| 扩内需促消费 | 让老百姓敢花钱、愿花钱 |
| 优化营商环境 | 让企业少跑腿、少填表、少折腾 |
| 数字经济发展 | 让数据跑起来，让算力沉下去 |

### 4. 口播词禁忌

- 忌长篇大论（单句不超过25字）
- 忌连续使用公文术语（每100字至少1个生活化表达）
- 忌没有数据支撑的观点
- 忌结尾没有互动引导
- 忌使用"有关部门""相关文件"等模糊表述

## 三、PPT 分镜设计规范

### 1. 页面类型与设计原则

| 页面类型 | 用途 | 设计原则 | 动画建议 |
|----------|------|----------|----------|
| 封面页 | 抓眼球，立主题 | 大字标题 + 对比色背景 + 1个核心视觉元素 | 标题逐字出现或放大入场 |
| 数据页 | 展示核心数据 | 图表为主，数字放大，配简短注释 | 图表按数据系列依次出现 |
| 逻辑页 | 展示逻辑关系 | 流程图/思维导图，箭头清晰 | 按逻辑顺序逐步展示 |
| 案例页 | 落地案例 | 对比图/前后对比，场景化呈现 | 先出场景，再出数据 |
| 金句页 | 总结升华 | 大字金句，留白充足，1个核心关键词 | 金句淡入，背景变暗 |

### 2. 配色方案建议

| 风格 | 主色 | 辅助色 | 强调色 | 适用场景 |
|------|------|--------|--------|----------|
| 权威稳重 | 深蓝 #1a3a5c | 白色 #fff | 金色 #c49b2a | 经济政策、宏观分析 |
| 科技前沿 | 深紫 #2d1b69 | 浅灰 #f0f0f0 | 亮蓝 #4da6ff | 科技政策、数字化 |
| 民生温度 | 暖橙 #e85d3a | 米白 #faf5ef | 深绿 #2d6a4f | 民生政策、社会保障 |
| 绿色生态 | 深绿 #1b4332 | 浅绿 #d8f3dc | 亮黄 #ffd60a | 农业政策、生态环保 |

### 3. 排版铁律

- 每页不超过3个信息层级（标题 > 要点 > 注释）
- 每页文字不超过50字（不含数据标注）
- 核心数据字号不小于36pt
- 图表必须标注数据来源
- 颜色不超过3种（不含黑白灰）

## 四、爆款内容公式

### 高传播率内容的共同特征

1. **有冲突**：政策变化 vs 既有认知的落差
2. **有账本**：把抽象政策换算成具体数字（"每人每年多收入XX元"）
3. **有故事**：用1个具体案例带动1个政策解读
4. **有金句**：每段内容至少1句可截图传播的金句
5. **有互动**：结尾抛出问题，引导评论区讨论

### 标题公式

- **数字+对比**："这项政策，让XX从1000变成了10000"
- **疑问+悬念**："为什么国家突然要管XX？答案出乎意料"
- **场景+冲突**："你的XX正在悄悄变化，90%的人还没注意到"
- **权威+落地**："求是发话了，这件事和你的钱包直接相关"
