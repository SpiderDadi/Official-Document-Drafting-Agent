# 官方信源获取策略

> 所有信源均为公开可查的官方渠道，数据来源合法合规。

## 一、核心信源清单

### 1. 求是杂志（qstheory.cn）
- **定位**：中共中央机关刊，理论性最强
- **重点栏目**：
  - 头条文章（习近平总书记重要文章）
  - 要论（社论/评论员文章）
  - 经济（宏观经济政策解读）
  - 党建（全面从严治党）
  - 文化（意识形态与文化自信）
- **更新频率**：半月刊（每月1日、16日）
- **获取策略**：优先关注"头条"和"经济"栏目，提炼核心理论观点

### 2. 人民日报（paper.people.com.cn）
- **定位**：中共中央机关报，权威性最高
- **重点版面**：
  - 头版（要闻）：当日最重要的政策信号
  - 评论版（第5版）："人民时评""人民论坛"等评论文章
  - 经济版：产业政策、区域发展、企业动态
  - 科技版：前沿科技政策与创新动态
  - 民生版：教育、医疗、住房、养老等
- **更新频率**：每日
- **获取策略**：每日浏览头版标题 + 评论版2-3篇重点文章

### 3. 新华社（xinhuanet.com）
- **定位**：国家通讯社，消息发布最快
- **重点内容**：
  - 新华社通稿（权威发布）
  - 新华时评（评论员文章）
  - 经济参考（经济分析）
  - 新华全媒+（新媒体产品）
- **更新频率**：实时
- **获取策略**：关注"权威发布"和"新华时评"栏目

### 4. 国务院政策文件库（www.gov.cn）
- **定位**：国务院官方政策发布平台
- **重点内容**：
  - 国务院文件（国发、国办发系列）
  - 部门文件（各部委规章）
  - 政策解读（图解/文字解读）
  - 新闻发布会实录
- **更新频率**：每日
- **获取策略**：关注最新发布的政策性文件和解读

### 5. 部委官网
- **农业农村部（moa.gov.cn）**：农业政策、粮食安全、乡村振兴
- **科技部（most.gov.cn）**：科技政策、创新驱动、科研改革
- **国家发改委（ndrc.gov.cn）**：宏观经济、产业政策、价格政策
- **工信部（miit.gov.cn）**：制造业、数字化转型、中小企业

## 二、信源优先级

| 优先级 | 信源 | 适用场景 |
|--------|------|----------|
| P0（必读） | 人民日报头版、求是头条 | 每日必读，把握政策方向 |
| P1（重点） | 新华社通稿、国务院文件 | 重要政策发布，优先解读 |
| P2（关注） | 部委官网、人民日报评论版 | 行业政策追踪，深度解读 |
| P3（补充） | 各部委新闻发布会、政策解读 | 政策背景补充，细节核实 |

## 三、每日简报信息采集 SOP

1. **上午 8:00-9:00**：浏览人民日报电子版头版标题，标记重点文章
2. **上午 9:00-10:00**：浏览新华社"权威发布"栏目，检查是否有新政策发布
3. **上午 10:00-11:00**：浏览国务院政策文件库，检查新发布文件
4. **下午 14:00-15:00**：浏览部委官网（农业农村部/科技部/发改委），关注行业动态
5. **下午 15:00-16:00**：整理当日简报，评级解读潜力

## 四、信源使用注意事项

1. **时效性**：所有引用必须标注具体日期/期号
2. **准确性**：涉及数据、提法时必须核对原文，不可凭记忆引用
3. **完整性**：引用政策文件时标注文号（如"国发〔2026〕XX号"）
4. **版权**：引用原文不超过合理篇幅，标注出处
5. **脱敏**：不引用内部文件、涉密文件、未公开征求意见稿
