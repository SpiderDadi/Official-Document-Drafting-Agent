# 常用公文文种写作规范

> **数据来源声明**：以下内容基于《党政机关公文处理工作条例》（中办发〔2012〕14号）、《党政机关公文格式》（GB/T 9704-2012）及政府公开信息整理，均为公开可查的官方标准。

---

## 一、法定公文（15种）

根据《党政机关公文处理工作条例》，法定公文共15种：

### 1. 决议（适用于会议讨论通过的重大决策事项）
- **框架**：会议基本情况 → 决议事项（分条阐述） → 执行要求
- **特点**：权威性、规范性、集体性
- **注意**：必须经会议表决通过，落款为会议名称

### 2. 决定（适用于对重要事项作出决策和部署）
- **框架**：背景依据 → 决定事项（分条列明） → 执行要求或号召
- **特点**：约束力强，用于奖惩、变更、部署等
- **注意**：决定事项必须明确具体，可操作

### 3. 命令/令（适用于公布行政法规和规章、宣布施行重大强制性措施）
- **框架**：依据 → 命令事项 → 生效日期
- **特点**：最具权威性和强制性
- **注意**：发文机关级别有严格限制

### 4. 公报（适用于公布重要决定或重大事项）
- **框架**：导语 → 分项叙述 → 结语
- **特点**：新闻性、公开性
- **注意**：多用于发布统计公报、会议公报、新闻公报

### 5. 公告（适用于向国内外宣布重要事项或法定事项）
- **框架**：公告依据 → 公告事项 → 结语（"特此公告"）
- **特点**：公开性、广泛性
- **注意**：发文级别较高，基层机关慎用

### 6. 通告（适用于在一定范围内公布应当遵守或周知的事项）
- **框架**：通告缘由 → 通告事项 → 结语（"特此通告"）
- **特点**：周知性、约束性、专业性
- **注意**：与公告区别在于发布范围和执行力度

### 7. 通知（适用于发布、传达要求下级机关执行和有关单位周知或执行的事项）
- **框架**：通知缘由 → 通知事项（分条） → 执行要求
- **特点**：使用频率最高，适用范围最广
- **常见类型**：印发通知、转发通知、批转通知、会议通知、任免通知、工作通知
- **注意**：标题要准确反映通知类型，事项要具体明确

### 8. 通报（适用于表彰先进、批评错误、传达重要精神和告知重要情况）
- **框架**：事实叙述 → 分析评价 → 奖惩决定或希望要求
- **特点**：教育性、典型性、真实性
- **常见类型**：表彰通报、批评通报、情况通报
- **注意**：事实必须准确无误，分析要客观公正

### 9. 报告（适用于向上级机关汇报工作、反映情况、回复询问）
- **框架**：报告缘由 → 报告事项（分条叙述） → 结语
- **特点**：陈述性、单向性、事后性
- **常见类型**：工作报告、情况报告、专题报告、回复报告、呈送报告
- **注意**：报告中不得夹带请示事项，不要求上级回复

### 10. 请示（适用于向上级机关请求指示、批准）
- **框架**：请示缘由（充分说明） → 请示事项（明确具体） → 结语
- **特点**：期复性、单一性（一文一事）
- **注意**：不得越级请示，不得多头请示，一文一事

### 11. 批复（适用于答复下级机关请示事项）
- **框架**：批复引据（引用来文） → 批复内容（明确表态） → 结语
- **特点**：针对性、指示性、被动性
- **注意**：态度必须明确，不能含糊其辞

### 12. 议案（适用于各级人民政府按法律程序向同级人大或人大常委会提请审议事项）
- **框架**：案由 → 方案 → 结语
- **特点**：法定性、程序性
- **注意**：有严格的提出主体和程序要求

### 13. 函（适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项）
- **框架**：发函缘由 → 事项 → 结语
- **特点**：平等性、灵活性、广泛性
- **常见类型**：商洽函、询问函、答复函、请批函、告知函
- **注意**：语气要谦和，不使用命令式语言

### 14. 纪要（适用于记载会议主要情况和议定事项）
- **框架**：会议基本情况 → 会议主要精神 → 议定事项
- **特点**：纪实性、概括性、指导性
- **注意**：不同于会议记录，需提炼概括

### 15. 意见（适用于对重要问题提出见解和处理办法）
- **框架**：提出问题 → 分析问题 → 解决意见
- **特点**：指导性、建议性、多向性
- **注意**：意见要具体可行，具有操作性

## 二、常用事务文书

### 1. 领导讲话稿
- **框架**：开场白（点题） → 主体（分点阐述） → 结束语（号召/希望）
- **特点**：口语化、针对性、鼓动性、政治性
- **类型**：
  - 工作会议讲话：重在部署、分析、要求
  - 动员大会讲话：重在鼓劲、号召、统一思想
  - 总结表彰讲话：重在肯定成绩、总结经验、提出希望
  - 汇报交流讲话：重在展示亮点、分享经验、谦虚表态
  - 庆典致辞：重在祝贺、回顾、展望
- **写作要点**：
  - 开头要有力，吸引注意力
  - 主体条理清晰，层次分明
  - 结尾要有号召力
  - 注意口语化表达，避免过于书面化
  - 适当使用排比、对仗等修辞手法

### 2. 工作总结
- **框架**：基本情况 → 主要做法/成效 → 存在问题 → 下一步打算
- **特点**：回顾性、经验性、规律性
- **类型**：年度总结、专项总结、阶段性总结
- **写作要点**：
  - 以数据说话，避免空泛
  - 突出重点，不要面面俱到
  - 问题分析要客观深入
  - 下一步打算要具体可行

### 3. 述职报告
- **框架**：履职基本情况 → 主要工作成效 → 存在不足 → 改进措施
- **特点**：个人性、述职性、考核性
- **写作要点**：
  - 用第一人称
  - 德能勤绩廉全面覆盖
  - 数据支撑，实例佐证
  - 不足要诚恳，改进要具体

### 4. 调研报告
- **框架**：调研背景 → 基本情况 → 问题分析 → 对策建议
- **特点**：客观性、系统性、对策性
- **写作要点**：
  - 数据详实，来源可靠
  - 问题分析要有深度
  - 建议要有可操作性
  - 适当运用图表辅助

### 5. 经验交流材料
- **框架**：背景简介 → 主要做法（分条） → 取得成效 → 体会启示
- **特点**：典型性、示范性、启发性
- **写作要点**：
  - 突出特色和亮点
  - 做法要具体可复制
  - 成效要可量化
  - 启示要有普遍意义

### 6. 实施方案
- **框架**：指导思想 → 工作目标 → 主要任务 → 时间安排 → 保障措施
- **特点**：操作性、系统性、时效性
- **写作要点**：
  - 任务分解要具体到责任单位
  - 时间节点要明确
  - 保障措施要务实
  - 目标要可量化考核

### 7. 会议纪要
- **框架**：会议概况 → 会议议题 → 议定事项 → 部署要求
- **特点**：纪实性、决议性、执行性
- **写作要点**：
  - 准确反映会议精神和决定
  - 议定事项要明确责任人和时限
  - 语言要概括精炼
  - 不宜逐字逐句记录

## 三、写作常用动词库

### 组织推进类
健全、夯实、完善、强化、推进、深化、提升、优化、构建、打造、营造、统筹、协调、整合、凝聚、激发、释放

### 措施落实类
落实、贯彻、执行、实施、部署、安排、推动、促进、督促、指导、检查、考核、问责

### 发展成效类
增长、提升、突破、跨越、跃升、迈上、实现、超额、达标、领先、首创、率先

### 问题解决类
纾解、化解、破解、缓解、打通、消除、补齐、弥补、攻克、扭转、整顿

### 改革创新类
创新、改革、探索、试点、示范、引领、驱动、赋能、转型、升级、突破

### 总结表态类
坚持、贯彻、围绕、按照、着力、聚焦、突出、注重、立足、对标
